Polyglot (formerly ItemLoc)

Find any item by name, in any language. You play in one language, but found the item name on a website in another? Paste it into the Polyglot window and get the item with its names in every language you chose, its icon and the regular in-game tooltip.

Example: you play in Russian and read "Thunderfury" on an English guide. Paste it, and see "Громовая Ярость" and "Donnerfury" next to it.

Features

  • Item tooltips in other languages: names in your chosen languages appear at the bottom of the normal item tooltip. Choose in the settings: off, one line (one extra language), a line per language, or a line per language only while Alt is held (default).
  • Places tab: names of zones, subzones, dungeons, raids and battlegrounds in the languages you chose (/pg zone <name>). Click a place to open its map; for dungeons the entrance is marked. Mobs and NPCs are not covered yet.
  • Nine languages: English, Russian, German, French, Spanish, Italian, Portuguese, Korean and Chinese. English is always on; enable only the others you need.
  • Strict and loose search. Strict needs the full name, loose finds part of a name or several words in any order. Case does not matter, including Cyrillic and accented letters.
  • Favorites: mark an item with a star and open your list with one click.
  • Real game data: icon, quality colour, type, level and the full tooltip come from your own client, so they always match your game version. Shift+click inserts the item link into chat.
  • Easy to open: minimap button, the /pg command, the addon menu and a bindable key.
  • Interface in English and Russian with a one-click RU/EN switch.
  • Light on memory: every language is a separate module that loads only when you enable it.

Quick start

  1. Install the addon (see below) and log in.
  2. Click the book button by the minimap or type /pg.
  3. Paste an item name and press Enter.
  4. Need another language? Click Languages... (or type /pg lang) and tick it.

All commands: /pg help.

Installation

Copy all folders from the archive (Polyglot, Polyglot_enUS, Polyglot_ruRU, and so on) into Interface\AddOns. Languages you do not need can be deleted, except Polyglot_enUS. Fully restart the game after installing. In the addon list the language modules are grouped under Polyglot.

FAQ

I used ItemLoc before. This is the same addon under a new name. Delete the old ItemLoc and ItemLoc_* folders from Interface\AddOns before installing. If the old addon is still enabled at your first login, your settings and favorites are copied automatically. The old /il command still works; the key binding has to be set again.

"Module Polyglot_enUS not found". Only the Polyglot folder was copied. Copy all Polyglot_* folders too and restart the game.

An item is not found. Check that the language you search in is enabled (/pg lang) and try loose mode. Names come from client data tables, so some very new Forever items may be missing for now. Please report them on GitHub with the output of /pg info.

The game was updated. Polyglot tells you at login if its name database was built for another client build. A new version is published automatically; just update the addon.

Support

Bugs and missing items: GitHub Issues. Please include the output of /pg info.

Polyglot (по-русски)

Поиск предметов по названию на любом языке. Играете на одном языке, а название предмета нашли на сайте на другом? Вставьте его в окно Polyglot и получите предмет с названиями на выбранных языках, иконкой и обычным тултипом из игры.

Пример: вы играете на русском и прочитали «Thunderfury» в английском гайде. Вставляете название и видите рядом «Громовая Ярость» и «Donnerfury».

Возможности

  • Девять языков: английский, русский, немецкий, французский, испанский, итальянский, португальский, корейский и китайский. Английский включён всегда, остальные включайте по необходимости.
  • Строгий и нестрогий поиск. Строгий требует полное название, нестрогий находит часть названия или несколько слов в любом порядке. Регистр не важен, в том числе для кириллицы и букв с диакритикой.
  • Избранное: отметьте предмет звёздочкой и открывайте список одной кнопкой.
  • Данные из самой игры: иконка, цвет качества, тип, уровень и полный тултип берутся из вашего клиента, поэтому всегда соответствуют версии игры. Shift+клик вставляет ссылку на предмет в чат.
  • Удобно открывать: кнопка у миникарты, команда /pg, меню аддонов и назначаемая клавиша.
  • Интерфейс на русском и английском, переключается одной кнопкой RU/EN.
  • Не нагружает память: каждый язык лежит в отдельном модуле и загружается, только когда включён.

Быстрый старт

  1. Установите аддон (см. ниже) и войдите в игру.
  2. Нажмите кнопку с книгой у миникарты или введите /pg.
  3. Вставьте название предмета и нажмите Enter.
  4. Нужен другой язык? Нажмите «Языки...» (или /pg lang) и отметьте его.

Все команды: /pg help.

Установка

Скопируйте все папки из архива (Polyglot, Polyglot_enUS, Polyglot_ruRU и так далее) в Interface\AddOns. Ненужные языки можно удалить, кроме Polyglot_enUS. После установки полностью перезапустите игру. В списке аддонов модули языков сгруппированы под Polyglot.

Вопросы и ответы

«Не найден модуль Polyglot_enUS». Скопирована только папка Polyglot. Скопируйте и все папки Polyglot_*, затем перезапустите игру.

Предмет не находится. Проверьте, что язык, на котором вы ищете, включён (/pg lang), и попробуйте нестрогий режим. Названия берутся из клиентских таблиц данных, поэтому самые новые предметы Forever могут пока отсутствовать. Сообщите о них на GitHub и приложите вывод /pg info.

Игра обновилась. При входе Polyglot сообщит, если база названий собрана для другой сборки клиента. Новая версия выходит автоматически, достаточно обновить аддон.
